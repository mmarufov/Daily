# Daily Lab

An evaluation instrument with a cinematic opening. The evidence supplies every visual.

## Visual system

- Near-white canvas #FAFAF9; graphite #171717; secondary #626262; rule #DEDEDA.
- Dark instrument #111315 with high-contrast readable controls. Red means failure/loss, green confirmed acceptance, amber incomplete. Always include text.
- Vendored Geist Sans for product copy; Geist Mono for quantities, code and identifiers. Fraunces remains reserved for the sample newspaper.
- Content max 1280px, generous section gaps, asymmetric hero, single-column mobile. Controls at least 44px, visible focus, 6-10px radii.
- One main artifact per homepage section. Headings and actions visible on the first render; never animate their initial opacity.

## Interaction

- Exact 1,362-cell recorded sieve, stable positions, one approximately five-second replay. Pause when hidden/offscreen; interaction takes control. Reduced motion starts settled.
- Cells express counts, never fabricated article identities. Actual article drilldowns use recorded stories.
- Four homepage acts: the instrument, retrieval losses, historical guard experiment, runnable parser.
- Real executions only after an explicit Run action. Genuine stage events precede completed case grading. Never simulate live progress.

## Evidence and accessibility

- Pin narrative artifact IDs and validate inputs. Keep missing separate from zero.
- Guard comparison is the September 21 experiment, not a shipped backend change or current CI status.
- Criteria are versioned and hashed; both generations remain inspectable. Acceptance is eligibility for review, not production promotion.
- Every chart has readable textual values. Controls work by touch, keyboard and pointer. The 1,362 marks are one accessible figure, not 1,362 tab stops.

## Release

Typecheck, unit tests, artifact checks and production build precede release. Browser QA targets marufov.com without a localhost server. Routine execution tests intercept API calls; one explicit real parser run establishes live execution. Capture mobile/desktop screenshots, run URL, deployment and lab performance results.
